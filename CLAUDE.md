# soypaulasofia.com

Media kit de Paula Sofía. Sitio estático de un solo archivo: `index.html` (HTML + CSS + JS inline, fuentes de Google Fonts).

## Publicación
- Hosting: GitHub Pages desde la rama `main` (raíz). Cada `git push` a `main` publica en https://soypaulasofia.com en ~1 minuto.
- Dominio registrado en Hostinger; DNS apunta a GitHub Pages (A: 185.199.108-111.153, CNAME www -> jfelipexlr.github.io).
- El archivo `CNAME` mantiene el dominio personalizado: no borrarlo.

## Flujo de edición (cualquier computador)
1. `git clone https://github.com/jfelipexlr/soypaulasofia.com.git && cd soypaulasofia.com`
2. Editar `index.html` (abrirlo en el navegador para previsualizar).
3. `git add -A && git commit -m "..." && git push`
